# Utter brand

The official Utter logo, mark and icon, for articles, partner pages and listings.

## Files

Every file comes as SVG and PNG, in [`logos/`](logos). The PNGs have transparent backgrounds, except the icon.

The [cover image](cover.png) is 1280 by 640, for README headers and link previews.

The mark is a U made of four lines nested inside each other. Each line stops at a different height, like the bars of a voice meter. The icon is the mark on Utter navy, for profile pictures and app icons.

## Using the logo

- Write the name as one word with a capital U: Utter.
- Use the full logo when people may not know the name yet, and the mark or icon on its own where they already do.
- Use the color or black logo on light backgrounds, and the light or white one on navy or dark backgrounds.
- Use the files as they are: don't stretch, crop, recolor, or add shadows or effects.
- Leave space around the logo, and don't put it on a busy photo.
